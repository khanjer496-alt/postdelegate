How to test PostDelegate

Use the reviewer credentials supplied in the platform review submission. The reviewer workspace contains only test channels and original sample media. It has no access to customer workspaces. Never enter personal information in sample posts.

  1. Sign in to PostDelegate with the reviewer email and password. Select PostDelegate Platform Review.
  2. Choose Add channel, select the network named in your review, and complete that network’s real sign-in and consent. Use the test account assigned to the existing platform app. Complete this step promptly; connection links expire.
  3. For Facebook, Instagram via Facebook, or LinkedIn Pages, select the authorized test Page. Instagram must be a professional account. For Pinterest, choose a board that already exists.
  4. Create a post in the calendar. Write a short original test caption, upload your original image or video, and select only the test channel. Instagram requires an image or video. Threads also supports text-only posts.
  5. For TikTok, wait for creator information to load, explicitly choose Only you for private testing, choose interaction settings, complete any required disclosure, and accept the music usage consent. Choose Direct Post to publish; inbox upload requires you to finish in TikTok.
  6. Publish the post and wait for processing to finish. Open the result on the platform. A TikTok private post may have no public link; check it in the creator account. Pinterest trial Pins are visible only to the app owner.
  7. To remove the test connection, open the channel menu and disconnect it. Data deletion instructions explain how to request removal of platform data or your account.

Optional analytics, comments and reply automations depend on separately approved permissions. A notice about an optional permission does not prevent publishing. Platform business verification and API approvals are separate from this testing flow.
