LinkedIn **personal profiles** are available now. LinkedIn **company Pages** are still [waiting on approval](/docs/channels/coming-soon); connecting your profile does not grant Page publishing access.

## Connect your profile

1. On the calendar, choose **Add Channel** and select **LinkedIn**.
2. Finish LinkedIn sign-in and return to PostDelegate promptly. A connection link can expire if it is left open.
3. Check that the connected profile is the one you intend to use before drafting or scheduling a post.

LinkedIn may use the account already signed in to that browser without another account picker. To connect a different profile, sign out of LinkedIn or switch accounts there first, then start **Add Channel** again. Reconnecting the same profile updates its existing channel.

## Prepare a post

Select the profile in the composer, add the text and optional media, and review the preview. Read the channel's current rules before posting through the API or an assistant. The API/MCP provider identifier is `linkedin`.

Personal-profile posts use **public visibility**. Do not use this connection to test private content. Choosing a schedule is not proof that a post has published; check its result in PostDelegate and on LinkedIn.

## Company Pages

The `linkedin-page` connection uses a separate developer app and remains unavailable until its permissions are approved and tested. No approval date is promised. Connecting an administrator's personal profile does not enable the company's Page.
